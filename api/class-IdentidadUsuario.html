Class IdentidadUsuario

IdentidadUsuario es una instancia de la clase CUserIdentity

IdentidadUsuario es una clase base para la representación de identidades que se autentican basandose en un nombre de usuario y una contraseña. Las clases derivadas deben implementar la autenticación con el esquema de autenticación real @example nombre de usuario y contraseña verificados contra una tabla DB.
