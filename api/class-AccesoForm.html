Class AccesoForm

AccesoForm Modelo para la autentificación de usuarios

Esta es una clase modelo que sirve para la autentificación de usuarios, a partir de un usuario y una contraseña proporcionados, estableciendo reglas y mensaje de errores para feedback del usuario que intenta loguearse
